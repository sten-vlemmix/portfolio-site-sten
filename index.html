Mijn project

Spotify Muziekspeler voor thuis

Muziek luisteren in huis, zonder je telefoon erbij te pakken.

StatusWerkend
Jaar2025
TechniekRaspberry Pi • Python

Waar gaat dit project over?

Voor dit project heb ik een muziekspeler gemaakt voor thuis. Hij werkt met Spotify en draait op een Raspberry Pi.

Je zet hem aan en je kunt thuis makkelijk muziek luisteren, bijvoorbeeld in de woonkamer. Gewoon aanzetten en luisteren.

Hoe heb ik het gemaakt?

1

Idee bedacht. Een muziekspeler die altijd klaarstaat.

2

Raspberry Pi klaargezet en verbonden met wifi en Spotify.

3

Met Python de knoppen gemaakt voor play en pauze.

4

Alles thuis getest tot het werkte.

Wat heb ik geleerd?

  • Werken met een Raspberry Pi
  • Programmeren in Python
  • Verbinden met Spotify
  • Rustig blijven als iets niet werkt
